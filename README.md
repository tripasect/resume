# Alireza Sadjadipour — Portfolio

Personal portfolio and resume website built with React, Three.js, and Framer Motion. Features a 3D interactive background and a multi-chapter narrative layout showcasing projects across web apps, AI systems, motion graphics, networking, sound, and languages.

Built with:
- React 19
- Three.js / @react-three/fiber + drei
- Framer Motion
- Vite
- Express (server-side)
- Cloudflare Pages (deployment)

## Development

```bash
npm install
npm run dev          # starts both Vite dev server + Express backend
npm run dev:frontend # Vite only
npm run build        # production build into dist/
npm run preview      # preview production build
```

## Deployment

Deployed via Cloudflare Pages. Build output directory: `dist/`.
